# 0006 · SEO

**Status:** accepted

## Context

A personal site has two search jobs: be the clear result for the owner's name, and earn long-tail traffic
from the work itself. "Subham Raj" is a common name, so the site must make it unambiguous which Subham Raj
this is.

## Decision

- **One entity.** Every page's JSON-LD references the same `Person` by `@id`, with `sameAs` links to LinkedIn
  and GitHub, which link back. The homepage is a `ProfilePage`.
- **Static, clean URLs.** Every word is in the HTML at build time. URLs have no trailing slash and no `.html`;
  canonical links, the sitemap and internal links all agree.
- **Social previews are part of SEO.** A build-time image per page, so shares on LinkedIn carry the title and
  the headline number.
- **Content over tricks.** Case studies and write-ups target what engineers actually search for. No keyword
  stuffing, no fake ratings. Unapproved metrics never render (ADR 0003).
- **Drafts never ship.** Posts default to `draft: true` and are excluded from builds until reviewed.

## Consequences

- Ranking for the bare name cannot be guaranteed; "Subham Raj frontend" and "Subham Raj React" are realistic.
- Moving from the old domain relies on page-level 301s and Search Console's Change of Address
  (docs/launch-checklist.md).
